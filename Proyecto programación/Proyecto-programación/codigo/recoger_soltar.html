Descripción

El electroimán se activa cuando el brazo robótico se posiciona en la ubicación del objeto detectado. Una vez que el objeto es atraído y asegurado, el brazo se mueve hacia la zona de destino. Al llegar, el electroimán se desactiva, liberando el objeto en la ubicación deseada.

Este proceso se controla a través de la Raspberry Pi Pico W, que gestiona la activación y desactivación del electroimán en sincronización con el movimiento del brazo.

Diagrama

Funcionamiento

1. Detección del Objeto

  • La cámara del sistema identifica la presencia del objeto.
  • El brazo se mueve automáticamente hacia la posición del objeto detectado.

2. Activación del Electroimán

  • Cuando el brazo llega a la posición del objeto, el electroimán se activa.
  • El objeto metálico es atraído y asegurado por el imán.

3. Transporte del Objeto

  • El brazo robótico se mueve hacia la caja o el destino definido.
  • El sistema mantiene el electroimán activo para sujetar el objeto durante el traslado.

4. Liberación del Objeto

  • Al llegar a la posición final, el electroimán se desactiva.
  • El objeto se suelta en la ubicación indicada.

Este mecanismo permite un manejo eficiente de objetos metálicos, optimizando la automatización del proceso de recolección y colocación dentro del sistema robótico.
