Control remoto

Descripción

p>El control remoto opera mediante un servidor web alojado en la Raspberry Pi Pico W. Una vez conectado a la red Wi-Fi, el usuario puede acceder a la interfaz de control ingresando la dirección IP del servidor en un navegador. Desde esta interfaz, se pueden ajustar los movimientos del brazo de forma intuitiva.

Cuando el usuario interactúa con los controles de la interfaz, los comandos se envían a la Raspberry, que los procesa y transmite las señales correspondientes a los servomotores.

Diagrama

Funcionamiento

1. Establecimiento de la Conexión

  • El código en CircuitPython configura la Raspberry Pi Pico W como un servidor web.
  • Se conecta a la red Wi-Fi y genera una dirección IP accesible para el usuario.

2. Acceso a la Interfaz de Control

  • El usuario abre un navegador web e ingresa la dirección IP proporcionada por la Raspberry.
  • Se carga una página HTML con controles de movimiento, como botones o sliders.

3. Envío y Procesamiento de Comandos

  • Cuando el usuario interactúa con los controles, se envían peticiones HTTP a la Raspberry.
  • El código en CircuitPython recibe estas peticiones y traduce los comandos en señales PWM para los servomotores.

4. Movimiento del Brazo

  • Los servomotores ajustan su posición según las órdenes recibidas.
  • El brazo robótico replica los movimientos realizados en la interfaz web.

Este sistema de control remoto permite una manipulación sencilla y eficiente del brazo robótico sin necesidad de conexiones físicas, facilitando su uso y ampliando sus aplicaciones.
