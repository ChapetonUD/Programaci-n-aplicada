Detectar

Descripción

Cuando la cámara detecta un objeto, el brazo robótico se mueve hacia una posición fija donde se espera encontrarlo. Una vez allí, tras un pequeño retraso, un relé activa el flujo de corriente hacia el electroimán, permitiendo que el objeto sea sujetado. Luego, el brazo transporta el objeto a otra posición fija donde se encuentra la caja, desactiva el electroimán y deja caer el objeto.

Después de completar la tarea, el brazo regresa a su posición inicial, quedando en espera de la próxima detección de un objeto.

Diagrama

Funcionamiento

1. Detección del Objeto

  • La cámara OV7670 escanea el área en busca de objetos.
  • Cuando se detecta un objeto, el sistema activa la secuencia de movimiento del brazo.

2. Movimiento Hacia la Posición del Objeto

  • El brazo robótico se mueve hacia la ubicación fija donde se encuentra el objeto.
  • Se espera un breve período de tiempo para asegurar la alineación correcta.

3. Activación del Electroimán

  • Un relé se activa, permitiendo que la corriente fluya hacia el electroimán.
  • El electroimán genera un campo magnético que atrae y sujeta el objeto.

4. Transporte del Objeto

  • El brazo robótico se mueve hacia la caja de destino.
  • El electroimán mantiene el objeto asegurado durante el traslado.

5. Liberación del Objeto

  • Al llegar a la caja, el sistema desactiva el flujo de corriente.
  • El electroimán pierde su magnetismo y el objeto cae dentro de la caja.

6. Retorno a la Posición Inicial

  • El brazo regresa a su posición inicial, listo para detectar un nuevo objeto.

Este proceso automatizado permite la manipulación eficiente de objetos sin intervención humana, optimizando la recolección y organización dentro del sistema robótico.
